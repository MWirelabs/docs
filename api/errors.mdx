---
title: Errors
description: One error shape, used by every endpoint.
---

Failures return a status code and a short message.

```json
{ "error": "audio must be 16 kHz mono wav" }
```

| HTTP status | Meaning |
|---|---|
| 400 | Missing or malformed field, or a limit exceeded |
| 401 | Missing or bad API key |
| 404 | Language or pair not served on this route |
| 500 | `model error`, retry later |
| 503 | `starting up`, the model is still loading. Retry in a few seconds |

Each endpoint page lists its exact `error` messages.
