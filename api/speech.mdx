---
title: Speech (TTS)
description: Lemka TTS. One path per language, Khasi and Garo live.
---

<Info>Status: **Live** for Khasi (`kha`) and Garo (`grt`). English Kokoro on `/speak` is not this product.</Info>

```
POST https://<HOST>/v1/audio/speech/{language}
```

### Auth

```
Authorization: Bearer <API_KEY>
```

### Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `text` | string | Yes | Text in that language. Up to 1000 characters. |

### Response

```json
{
  "audio_b64": "<base64 wav>",
  "duration_sec": 3.2
}
```

### Streaming

```
POST https://<HOST>/v1/audio/speech/{language}/stream
```

Same body. The response is raw audio bytes sent as they are generated. The sample rate is in the `X-Sample-Rate` header.

### Errors

| Status | `error` |
|---|---|
| 400 | `text is empty` |
| 400 | `text too long` |
| 404 | `language not served` |
| 503 | `starting up` |
