---
title: Get access
description: Sign up in the console, or request an on-prem image.
---

**Hosted API:** sign up at [console.mwirelabs.com](https://console.mwirelabs.com) and create an API key. See the [Quickstart](/quickstart).

**On-prem image or gated weights:** email [connect@mwirelabs.com](mailto:connect@mwirelabs.com) with:

- Organisation and use (research, gov, product)
- Languages and product (ASR / TTS / text)
- On-prem GPU or CPU target
- Whether you need the Docker API image or weights only

Gated Hugging Face repos: request on the model card, or use the same email.
