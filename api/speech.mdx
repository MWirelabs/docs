<Info>Status: **Planned**. No NE-language voice is live yet; the current demo TTS is an English fallback, not a NE voice.</Info>

Mono TTS: one checkpoint, one speaker, per language. The language is in the path, not the body.

### Endpoint pattern

```
POST https://<HOST>/v1/audio/speech/{language}
```

`{language}` is one of the codes in the table below.

### Auth

```
Authorization: Bearer <API_KEY>
```

### Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `text` | string | Yes | Text to synthesise, in that language. |
| `format` | string | No | Output container. Defaults to `wav`. |

### Response

```json
{
  "language": "kha",
  "audio_b64": "<base64 wav>",
  "format": "wav",
  "request_id": "req_8f2a1c"
}
```

### Errors

See [Errors](/api/errors). A language returns `503 model_unavailable` until its voice is licensed and marked live below.

### Language support

| Path | Language | Status |
|---|---|---|
| `/v1/audio/speech/kha` | Khasi | Planned |
| `/v1/audio/speech/grt` | Garo | Planned |
| `/v1/audio/speech/trp` | Kokborok | Planned |
| `/v1/audio/speech/lus` | Mizo | Planned |
| `/v1/audio/speech/nag` | Nagamese | Planned |
| `/v1/audio/speech/mni` | Meitei | Planned |

Every path requires voice-talent consent before it is marked live. See [Licenses](/licenses/overview).

### Example

```bash
curl -s https://<HOST>/v1/audio/speech/kha \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"khublei"}'
```
