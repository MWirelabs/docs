---
title: Translate
description: Text translation between English and Khasi or Garo.
---

<Info>Status: **Live** for English to and from Khasi and Garo. Other pairs on request.</Info>

```
POST https://<HOST>/v1/translate
```

### Auth

```
Authorization: Bearer <API_KEY>
```

### Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `text` | string | Yes | Source text. Up to 5000 characters. |
| `source` | string | Yes | `eng`, `kha` or `grt`. |
| `target` | string | Yes | `eng`, `kha` or `grt`. |

One side of every pair must be `eng`. Khasi to Garo is not served.

### Response

```json
{
  "translation": "translated text"
}
```

| Pair | Status |
|---|---|
| Khasi to and from English | Live |
| Garo to and from English | Live |

### Errors

| Status | `error` |
|---|---|
| 400 | `text is empty` |
| 400 | `text too long` |
| 404 | `language pair not served` |
| 503 | `starting up` |
