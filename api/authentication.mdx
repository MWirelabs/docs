---
title: Authentication
description: Bearer API keys created in the console.
---

Create a key in the [console](https://console.mwirelabs.com) under Your keys. Send it on every `/v1` call.

```
Authorization: Bearer <API_KEY>
```

- Up to 5 active keys per account.
- Keep keys on your server, never in an app or web page.
- A key you no longer use can be removed in the console.

| Status | Meaning |
|---|---|
| 401 | Missing or bad key |

<Warning>
The legacy `POST /speak` demo has no auth. Do not expose it on a public network.
</Warning>
