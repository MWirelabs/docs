Two stacks. Do not mix them up.

<CardGroup cols={2}>
  <Card title="NE-ASR" icon="download" href="/integrations/huggingface">

  </Card>
  <Card title="LEMKA" icon="server" href="/api/transcriptions">

**Languages:** Khasi, Garo, Kokborok, Mizo, Nagamese, Meitei. Coverage depends on the release.

## LEMKA - API

Licensed model. Not published as open weights.

| Status | What |
|---|---|
| Live demo | Garo path on `POST /speak` |
| Planned | `POST /v1/audio/transcriptions` on the licensed image |

## NE-ASR - open weights

[MWirelabs/ne-asr](https://huggingface.co/MWirelabs/ne-asr). Load with `transformers` or CTranslate2. No API key. **Not** the LEMKA checkpoint.

<Warning>
A licensed Docker image runs **LEMKA**. Pulling NE-ASR from Hugging Face does not give you the commercial API.
</Warning>
