---
title: Rate limits
description: No public default. Set per license or pilot agreement.
---

There is no fixed public rate limit. This is an on-prem, licensed API, not a shared multi-tenant service.

- **Demo images**: limits, if any, are set for the pilot and communicated directly.
- **Licensed production images**: throughput is bound by your own GPU, not by MWire. Concurrency limits are a config value in your runbook, not a contract term.
- **429 responses** only occur if you configure a limit yourself, or during a time-boxed demo/pilot.

No SLA or uptime commitment is implied by this page. See [Access](/access) for what a license agreement does cover.
