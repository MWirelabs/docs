title: Transcriptions (ASR)
description: Lemka speech to text. Khasi and Garo live.
---

<Info>Status: **Live** for Khasi (`kha`) and Garo (`grt`). Other languages on request. Legacy [`/speak`](/api/speak) is a Garo-only demo.</Info>

```
POST https://console.mwirelabs.com/v1/audio/transcriptions
```

### Auth

```
Authorization: Bearer <API_KEY>
```

### Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `audio_b64` | string | Yes | Base64 of a 16 kHz mono WAV. |
| `language` | string | Yes | `kha` or `grt`. |

### Limits

- Clip length: 0.2 to 120 seconds.
- Request body: 8 MB.
- Audio must be 16 kHz mono WAV.

For longer files, see [Long audio](/guides/long-audio).

No diarization, speaker ID, timestamps or language ID. One language per request.

### Response

```json
{
  "text": "transcribed text here",
  "duration_sec": 12.4
}
```

`duration_sec` is the length of the clip you sent.

### Errors

| Status | `error` |
|---|---|
| 400 | `audio is not a valid base64 wav` |
| 400 | `audio must be 16 kHz mono wav` |
| 400 | `audio length out of range` |
| 404 | `language not served` |
| 503 | `starting up` |
